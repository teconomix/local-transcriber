In short

This website sets no cookies, uses no tracking and no analytics services, and loads no third-party content (no external fonts, scripts or images). The Transcriber app works offline and does not send any data on its own – the only exception is an optional daily check of the current version number (see below). If you want, you can send problem reports yourself by email.

Visiting this website and downloads

This website is hosted by Uberspace (Jonas Pasche, Kaiserstr. 15, 55116 Mainz, Germany). When you open pages or download files – including the installation script, which is loaded from this server – the server must, for technical reasons, process the following data in order to answer the request:

  • IP address of the requesting device
  • date and time of access
  • requested address (URL), amount of data transferred and status code
  • browser or program identifier (user agent)
  • the page you came from (referrer), if your browser sends it

The purpose is to deliver the website securely and reliably and to prevent abuse. The legal basis is my legitimate interest under Art. 6(1)(f) GDPR.

Access log: Since October 15, 2026, the server stores this data in an access log – the IP address only in shortened form (for IPv4 the first two of four parts, 82.98.87.93 becomes 82.98.0.0; for IPv6 the first 32 bits). Uberspace deletes the log automatically after 7 days.

Reach measurement: Once a day I count from the log how often the pages were visited, the install script and the app were downloaded and – with the update notice turned on – the version number was checked, and which websites visitors came from. Only these daily totals are kept, without IP addresses or any other details about individual visitors. The purpose is to learn whether and how the free tool is used; the legal basis is my legitimate interest (Art. 6(1)(f) GDPR). There is no analysis for advertising purposes and no disclosure to others.

Cookies, tracking, third parties

This website sets no cookies and stores nothing in your browser. No analytics, tracking or advertising services are used. All fonts, images and scripts are loaded from this server. The link to GitHub is only accessed when you click it; from then on, GitHub’s privacy policy applies.

The Local Transcriber app

After installation, Transcriber works offline on your Mac. Recordings, transcripts, voice profiles and settings stay on your device; the app sends no data to me or to third parties. I receive neither usage statistics nor automatic crash reports (apart from the daily number of update checks, see reach measurement above).

Update notice (optional): When first opened, the app asks whether it may check for new versions. Only if you agree does it fetch the file latest.txt from this server once a day; the file contains only the current version number. The server processes the same data as when this website is accessed (see above; program identifier “Transcriber”), including the access log and the daily totals; the request contains nothing about you or your recordings. The legal basis is your consent (Art. 6(1)(a) GDPR), which you can withdraw at any time in the app’s settings (General).

Problem reports (voluntary): With “Report a problem” (ladybug icon in the panel), the app creates a ZIP file on your Mac in your Downloads folder and opens an email to info@teconomix.net with this file attached. The app sends nothing itself – you see the email and decide whether to send it. The file contains your description, the app’s logs, program version, Mac model, macOS version, the status of the permissions, the names of the audio devices and the app’s settings; it contains no recordings, no transcripts, no voice profiles and no glossary. File names, event titles, names of people, email addresses and your user name are replaced by placeholders beforehand unless you switch that off. I use the report and your email address only to investigate the problem and to reply to you, and delete both once the problem is resolved, at the latest after 12 months. The mailbox is hosted by Uberspace (see above). The legal basis is my legitimate interest in fixing problems and answering your request (Art. 6(1)(f) GDPR).

During installation, in addition to the files from this server, the installation script downloads further software directly from its providers: the uv tool from Astral (astral.sh, USA; uv in turn downloads Python and program files via GitHub, USA), Python packages from the Python Package Index (PyPI, Python Software Foundation, USA), the Whisper speech recognition model from Hugging Face (Hugging Face, Inc., USA) and – if not already present on the Mac – ffmpeg from ffmpeg.martin-riedl.de (Germany). In the process, your IP address is transmitted to these providers; their privacy policies apply.

Note: If you record conversations, you are responsible for obtaining the consent of those involved.
