Meeting transcripts in Obsidian – local, with speaker names as links

If your notes live in Obsidian, transcripts belong there too: one note per conversation, with date, calendar event and the participants as links to your people notes. Local Transcriber records and transcribes on your Mac; the plugin Local Transcriber for Obsidian turns each transcript into a note. Nothing is uploaded, and no account is needed.

What ends up in your vault

  • One note per recording in a folder of your choice (default Transcriber), with the properties date, duration, participants (as [[links]]), event, transcript and the tag transcript.
  • The transcript, by speaker – with the names Local Transcriber recognized from its local voice database.
  • Names you assign later reach the note, also a re-analysis or the descriptive file name the app gives a recording.
  • Audio files already in your vault: right-click › Transcribe. The note embeds the audio, so you can play it in Obsidian.

Your own notes stay yours

The plugin only updates the transcript section between two hidden markers. What you write above or below it is never touched. If you edit the transcript itself – say, to fix a misheard word – the plugin stops updating it and tells you. Renamed or moved notes are found again; deleted notes are not recreated. Changes travel one way only: from Local Transcriber to Obsidian.

Name speakers in Obsidian

In a transcript note, the command palette offers Name a speaker: pick the speaker, type a name – suggestions come from the calendar attendees and, optionally, a people folder. Local Transcriber's voice database learns the voice and recognizes it in future recordings. Confirm all speaker matches does the rest in one step.

Summaries – with whatever you like

The plugin itself sends nothing anywhere: no network use, no telemetry. If you want summaries, use the AI plugin of your choice on the note – local or not is then up to you.

Honestly: the limits

Macs with Apple Silicon only (macOS 14+), and Obsidian on the desktop – the plugin reads the transcript files on that Mac. It has been submitted to Obsidian's plugin directory; until it is listed there, it is installed by hand or with BRAT. If your vault is synced (Obsidian Sync, iCloud, Syncthing …), the transcript notes are synced too – choose the notes folder accordingly. And getting everyone's consent before recording is up to you.

Install

1. Local Transcriber: open Terminal (⌘ + Space, “Terminal”) and paste – the installer does the rest in about ten minutes:

curl -fsSL https://transcriber.teconomix.net/k/seo-obsidian-en/install.sh | bash

Or with Homebrew: brew install --cask teconomix/tap/local-transcriber. Guide with pictures and a 70-second video: home page.

2. The plugin: installation instructions on GitHub (by hand or with BRAT). Source code of both: open source (MIT).
